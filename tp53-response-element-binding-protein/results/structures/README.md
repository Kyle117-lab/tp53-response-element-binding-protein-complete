# Final model: id143

`id143_design_complex.pdb` is an unmodified copy of the user's uploaded **`143(1).pdb`**, which is the actual submitted research result (NOT the old attachment `143.pdb`, which was PDB 3KMD). SHA-256 is recorded in `results/id143_contact_audit.txt`.

Chains A/D contain the same 123-aa designed protein. Chains B/C are each 20-nt DNA with the sequence `GGGCATGCCTAGGCATGCCC`. The PDB carries coordinates but not Boltz JSON metrics, model weights, LigandMPNN source FASTA, or a proof of DNA binding. See main README and `docs/LIMITATIONS.md`.
